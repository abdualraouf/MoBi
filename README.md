# MoBi | نظام إدارة محلات الهواتف ونقاط البيع والصيانة (POS & Phone ERP)

نظام تشغيل وإدارة متكامل ومخصص لمحلات الهواتف النقالة وورش الصيانة ونقاط البيع السريعة، مصمم ليعمل محلياً بنسبة **100% بدون إنترنت (Offline-First)**، ويدعم قارئات وطابعات الباركود الحرارية، وتتبع أجهزة الهواتف برقم الـ **IMEI**، وإمكانية الحزم كملف تنفيذي مستقل (`MoBi.exe`).

---

## 🌟 أبرز مميزات النظام

1. **نقطة بيع سريعة (POS):**
   - قراءة فورية لباركود العلب المصنعي (UPC/EAN) للإكسسوارات والمستلزمات.
   - قراءة أرقام الـ **IMEI** للهواتف مع التحقق التلقائي من توفرها بالمخزون.
   - تنبيهات صوتية (Beeps) مدمجة عبر Web Audio API دون الحاجة لملفات صوت خارجية.
   - اختصارات لوحة المفاتيح (`F2` للبحث، `F4` للدفع، `F9` لتفريغ السلة).
   - طباعة فواتير وإيصالات حرارية قياسية (80mm و 58mm).

2. **تتبع دقيق للمخزون (IMEI & Serial):**
   - تسجيل الهواتف (جديدة أو مستعملة) برقم الـ IMEI الرئيسي والثانوي، اللون، السعة، وصحة البطارية.
   - طباعة ملصقات الباركود القياسية للأصناف غير المعرفة.
   - تنبيهات نقص المخزون.

3. **ورشة صيانة متكاملة (Maintenance Hub):**
   - إصدار تذاكر استلام الأجهزة وتوليد باركود التذكرة تلقائياً.
   - طباعة ملصق صغير يُلصق على ظهر هاتف الزبون لسهولة الوصول إليه.
   - خصم قطع الغيار تلقائياً من المخزون عند تركيبها للجهاز.
   - تتبع حالات الصيانة (مستلم، قيد الفحص، قيد الإصلاح، جاهز للتسليم، تم التسليم).

4. **الخزينة والتقارير والأرباح:**
   - جرد الخزينة اليومية ومطابقة النقد الفعلي (كاش، شبكة، آجل).
   - حساب صافي أرباح المبيعات (سعر البيع - سعر التكلفة).
   - تقارير إيرادات ورشة الصيانة.

5. **أدوار المستخدمين (RBAC):**
   - **المدير (Admin):** صلاحية كاملة على التقارير، تعديل الأسعار، وإعدادات المحل.
   - **الكاشير (Cashier):** واجهة البيع السريعة والعملاء.
   - **فني الصيانة (Technician):** ورشة الصيانة واستلام الأجهزة واستهلاك القطع.

## 🚀 طريقة التشغيل السريع للمطورين

```bash
# 1. تفعيل البيئة الافتراضية
.\venv\Scripts\activate

# 2. تشغيل النظام بنقرة واحدة
python run.py
```
سيقوم السكريبت بتهيئة قاعدة البيانات تلقائياً وفتح المتصفح فوراً على الرابط: `http://127.0.0.1:8000`.

### الحسابات الافتراضية للتجربة السريعة:
- **المدير:** `admin` / `admin123`
- **الكاشير:** `cashier` / `cashier123`
- **فني الصيانة:** `tech` / `tech123`

## 📦 إنتاج ملف تنفيذي مستقل للعميل (`MoBi.exe`)

لتحزيم النظام كاملاً بملف واحد لا يحتاج لتثبيت بايثون لدى العميل:

```bash
python package_app.py
```
ستجد الملف التنفيذي الناتج داخل مجلد `dist/MoBi.exe` جاهزاً للنقل والتشغيل مباشرة على أي جهاز Windows.
